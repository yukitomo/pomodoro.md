# Pomodoro.md Changelog

## [Initial Version] - {PR_MERGE_DATE}

- Start, stop, and switch pomodoro timers from Raycast with a menu bar countdown
- Manual mode: manage tasks directly in Raycast (no external files needed)
- Daily Note mode: load tasks from a markdown timetable and write pomodoro logs back to the same file
- Break timer with automatic resume of the previous task
- Quick Start command for a configurable default task
- Configurable pomodoro/break durations, daily note filename pattern, section headers, and break keywords
